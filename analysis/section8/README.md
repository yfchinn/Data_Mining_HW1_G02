# Section 8 — Statistical significance and error diagnostics (Python only)

This folder extends the existing `results/experiment_v2/` experiments. It **does not** retune or overwrite the models or their frozen test predictions. Run the scripts from a clone of the **full** `Data_Mining_HW1_G02` repository (not from this folder alone).

## Install (run from repository root)

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt -r analysis/section8/requirements-analysis.txt
```

On Windows PowerShell replace activation with `.venv\Scripts\Activate.ps1`.

## Reproduce the analysis

```bash
cd analysis/section8
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python analyze_section8.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python lasso_null_tests.py
```

Run in the order above: `lasso_null_tests.py` reads the coefficient tables generated by `analyze_section8.py`. The first command audits all 24 June 2026 rolling-Lasso forecasts against the frozen `experiment_v2` outputs, calculates standardized coefficients, VIFs, auxiliary OLS/HAC tests, resampling sensitivity intervals, feature-selection rates, residual diagnostics, test-error rankings, and comparisons with the original rolling-Lasso baseline. The second adds exploratory restricted-null bootstrap p-values for the representative Taipei-entry fit. It makes 1,999 bootstrap draws *per feature* and is noticeably slower.

Outputs: `analysis_results.json`, `data/*.csv`, and `figures/*.png`. These outputs are included in this package for reference; rerunning overwrites **only the files in this analysis folder**, not the original `results/experiment_v2/` data.

**Interpretation limitations.** The holiday-duration model was selected for discussion using test-set comparisons, so its apparent performance advantage is exploratory, not independent post-selection evidence. Lasso bootstrap intervals and restricted-null p-values are approximate, not formal selective inference; OLS/HAC p-values pertain to a separate auxiliary estimator. These models are refitted monthly and separately for 24 station/direction targets. Do not describe coefficients as causal or treat dependent station/month outcomes as independent replicates.

See the top-level repository README for the underlying forecast setup, source datasets, validation policy, and test period (July 2024–June 2026).
