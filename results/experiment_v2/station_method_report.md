# 各站預測表現比較

測試期間：2024-07～2026-06，共 24 個月。每站進站、出站分別評估，共 24 個目標。

- 前一年同月 t−12：每站每月以前一年同月的實際人次預測。
- B（baseline）：原本特徵，包含 long_holiday_count。
- H：以 started、ended 取代 long_holiday_count。
- HL：H 再加上 log1p(started)、log1p(ended)，保留原值。
- Rolling OLS window = 60 個月；Rolling Lasso window = 36 個月。
- 各方法沿用營運後資料、時間切分與逐月預測規則。
- MAE、RMSE、MAPE 越小越好；R² 越大越好。MAPE 單位為 %；MAE、RMSE 單位為人次。
